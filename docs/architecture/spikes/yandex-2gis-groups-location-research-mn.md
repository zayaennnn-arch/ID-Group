# Судалгаа: Yandex ID, Yandex Бизнес, 2ГИС «Друзья на карте» ба ижил төстэй системүүд

> Огноо: 2026-10-27 · Хариуцагч: business-analyst · Төлөв: draft
> Асуулт: Байгууллага, гэр бүл, найз, бусад группыг Hamuga ID дээр бүртгэх нь зөв үү? Бусад платформ үүргийг хэрхэн хуваасан бэ?
> Өмнөх судалгаа: [group-org-sso-research-mn.md](group-org-sso-research-mn.md) · [Процессын зураглал](../../requirements/process-map-group-org-mn.md)
> Арга: албан ёсны тусламжийн хуудас, үйлчилгээний нөхцөл, хэвлэлийн мэдээ (доорх §7). Апп-ыг өөрөө туршаагүй тул товчны нэр зэрэг жижиг зүйл өөрчлөгдсөн байж болно.

## 1. Хураангуй

1. **Yandex үүргээ гурван газар хуваасан:**
   - **Байгууллага** нь Yandex ID-д байна («Организации в ID»). Pay, Market for Business, «Yandex ID for websites» зэрэг олон үйлчилгээ нэг байгууллагын бүртгэлийг дахин ашиглана.
   - **Газрын зураг дээрх бизнесийн цэг** нь тусдаа Yandex Бизнес дээр байна.
   - **Байршил хуваалцах** нь Yandex Карты апп дотор байна (2026 оны 1-р сараас).
   - **Гэр бүл** ID-д байгаа ч зорилго нь зөвхөн захиалга, төлбөр хуваалцах. Байршил хуваалцахгүй.
2. **2ГИС, Kakao-д найз ба байршил хуваалцах нь апп дотор** байна. 2ГИС-д газрын зургийн апп, Kakao-д мессенжерийн чат. Identity системд найзын групп байдаггүй.
3. **Yandex ID-ийн байгууллагын role манай NAV-027-той бараг ижил:** Эзэмшигч, Админ, Гишүүн. Админ бусад админыг нэмж, засах эрхгүй.
4. **Yandex байгууллагыг бүртгэх үед баталгаажуулдаггүй.** ИНН-ээр хайгаад нэмэхэд л хэрэглэгч эзэмшигч болдог. Хариуцлагыг хэрэглэгч хүлээнэ, Yandex дараа нь баримт шаардаж болно. 2026 оны 9-р сараас Оросын засгийн газрын шийдвэрээр хуулийн этгээдийн бүртгэлийг Госуслуги-аар баталгаажуулах боломж нээгдэж байна. **Манай ДАН + ХУР-ын тулгалт** (хэрэглэгч = удирдлага) **үүнээс илүү найдвартай.**
5. **Бизнесийн цэг өмчлөх аргууд нь манай NAV-032-той ижил:**
   - Yandex Бизнес, 2ГИС хоёулаа цэг дээрх утас руу дуудлага эсвэл SMS-ээр код илгээдэг.
   - Цэг аль хэдийн эзэнтэй бол Yandex-д хоёр дахь хүн нь «Представитель» role авдаг.
6. **Дүгнэлт:** өмнөх зөвлөмж батлагдлаа. **Байгууллага ба баталгаажсан гэр бүлийн холбоо ID-д байна. Найз, бусад групп ба байршил хуваалцах газрын зургийн апп-д байна. Бизнесийн цэг POI engine-д байна** (§6).

## 2. Yandex ID

### 2.1 «Организации в ID»: байгууллагын бүртгэл

| Шинж | Yandex ID | Hamuga ID-ийн одоогийн загвар |
|---|---|---|
| Байршил | Identity түвшинд. Байгууллагын мэдээлэл ажилтны хувийн бүртгэлд биш, **байгууллагын тусдаа бүртгэлд** хадгалагдана. Ажилтан гарахад хандалт алдагдахгүй | ID-ийн «Миний групп» → «Байгууллага» төрөл |
| Хайх, нэмэх | ИНН, ОГРН, КПП, нэр, удирдлагын нэр, хаягаар хайгаад сонгоно | «Регистр эсвэл ТТД» ганц талбар |
| Татан буугдсан байгууллага | Хайлтад гарахгүй тул нэмэх боломжгүй | NAV-029 AC 3 «Регистр олдсонгүй» |
| **Төлөөлөх эрхийг шалгах** | **Шалгахгүй.** Нэмсэн хүн шууд **эзэмшигч** болно. Нөхцөлд «хэрэглэгч төлөөлөх эрхтэй гэдгээ баталж, хариуцлага хүлээнэ» гэж заасан. Yandex мэдээллийн үнэн зөвийг шалгахгүй ч хэзээ ч дүрэм, итгэмжлэл шаардаж, бүртгэлийг түр хааж болно | ДАН-аар нэвтэрсэн иргэн = ХУР-ын удирдлага → шууд; үгүй бол удирдлага ДАН-аар зөвшөөрнө |
| Госуслуги | 2026-09-07-ны № 2428-р шийдвэрээр Yandex, Avito, Ozon, VK зэрэгт хуулийн этгээд, ХХ-ийн бүртгэлийг Госуслуги-аар баталгаажуулах эрх нээгдсэн (хэвлэлийн мэдээ; Yandex ID-д хэрхэн хэрэгжсэнийг олсонгүй) | ДАН, ХУР (ижил санаа) |
| Role | **Эзэмшигч**: бүгдийг хийнэ, эзэмшлээ шилжүүлнэ, байгууллагыг устгана. **Админ**: гишүүн нэмж хасна, үйлчилгээний хандалт олгоно, гэхдээ **бусад админыг нэмж, засахгүй**. **Гишүүн**: харах, байгууллагын нэрээр үйлдэл хийх | NAV-027: Эзэмшигч / Админ / Гишүүн; Админ зөвхөн «Гишүүн»-ийг хасна (PO 2026-10-26) |
| Ажилтан нэмэх | Эзэмшигч автоматаар үүссэн **урилгын холбоос** илгээнэ. Нэгдэхэд ажилтны нэр, зураг бусад гишүүдэд харагдана | Урилга, ажлын имэйлийн домэйн, нэгдэх хүсэлт (NAV-028) |
| Байгууллагын нэрээр ажиллах | Баруун дээд булангийн профайлаас **байгууллагыг сонгож «байгууллагын горим» руу** шилжинэ. Хувийн горим руу буцаж болно | **Байхгүй** (§6.3) |
| Олон байгууллага | Нэг хүн хэд хэдэн байгууллага эзэмшиж болно. Хэд хэдэн байгууллагыг «Бизнес-группа» болгон нэгтгэж болно | Нэг хэрэглэгч 20 групп хүртэл |

### 2.2 «Семья»: гэр бүлийн групп

| Шинж | Yandex ID |
|---|---|
| Зорилго | **Plus, Yandex 360 захиалга, нэг банкны картаар төлөх**. Байршил хуваалцах тухай дурдаагүй |
| Хэмжээ | Админ + 7 гишүүн |
| Хязгаар | Нэг хүн **зөвхөн нэг** гэр бүлийн группт. Корпорацын бүртгэлд гэр бүл байхгүй |
| Урих | «Пригласить близкого» → холбоос, SMS эсвэл имэйл → «Принять приглашение» |
| Хүүхэд | Эцэг/эх хүүхдийн бүртгэлийг **өөрөө үүсгэнэ** (нэр, нас, контентын насны хязгаар 6+, 12+). Эсвэл хүүхдийн одоо байгаа бүртгэлийг «хүүхдийн бүртгэл» болгоно; хүүхэд өөрийн төхөөрөмж дээр зөвшөөрнө. Зөвхөн Орос, Беларусь |
| Админ гарах | Админ гарах, эрхээ шилжүүлэх **боломжгүй**, зөвхөн группыг устгана |
| Монгол | Бүртгэл нэгтгэх функц Монголд ажилладаг. Хүүхдийн бүртгэл, гэр бүлийн төлбөр Монголд ажилладаггүй |

**Hamuga ID-тэй харьцуулахад:**
- Hamuga-д эцэг/эх ба хүүхдийн холбоо **ДАН-аар нотлогддог** тул Yandex-ийнхаас найдвартай. Yandex-д эцэг/эх хүүхдийн бүртгэлийг өөрөө үүсгэнэ, баталгаажуулалт байхгүй.
- Yandex-ийн «нэг хүн нэг гэр бүл» дүрэм манай шийдвэрээс (олон гэр бүл, судалгаа §5 мөр 4) өөр. Yandex-д энэ дүрэм нь захиалга, төлбөр хуваалцахтай холбоотой.

## 3. Yandex Бизнес: газрын зураг дээрх цэг

| Шинж | Yandex Бизнес |
|---|---|
| Эхлэх | Yandex Карты дээр цэгийн карт → «Вы владелец этой организации?» эсвэл Yandex Бизнесийн кабинет |
| Баталгаажуулах | Цэг дээрх утас руу код илгээнэ. **Суурин утас** бол «Подтвердить звонком»: автомат оператор залгаж кодыг уншина. **Гар утас** бол SMS эсвэл дуудлага. Сүлжээ байгууллагад утсаа сонгоно |
| Баримт | Зөвхөн бизнес төвийн эзэмшигч role-д (үл хөдлөхийн гэрчилгээ) |
| Утас буруу бол | Эхлээд Yandex Карты дээр утсыг засна. Хүсэлтийг 3 хоногт хянана |
| Аль хэдийн эзэнтэй | Хоёр дахь хүн **«Представитель»** role авна. Эзэмшигч болохын тулд одоогийн эзэмшигчээс хүсэх эсвэл дэмжлэгт хандана (ИХ, ХХК-ийн бүртгэлийн баримттай) |
| Role | Эзэмшигч, Төлөөлөгч, Төлөөлөгч (Webmaster). Агентлаг эзэмшигч болохгүй, зөвхөн төлөөлөгч |
| Шилжүүлэх | «Доступы» хэсэгт Yandex ID оруулж role сонгоно. Хүлээн авагч зөвшөөрсөн тохиолдолд л шилжинэ |
| Видео, вывеска | Зарим тохиолдолд хаягаа нотлох вывеска, бичлэг шаарддаг гэж блогууд бичсэн. Албан ёсны хуудсанд байхгүй |
| Цэнхэр тэмдэг | Эрхээ баталгаажуулж, профайлаа бүрэн бөглөсний дараа олгоно. Мэдээллийг 3 сар тутам шинэчлэх шаардлагатай гэж блогууд бичсэн |

**NAV-032-той харьцуулахад:**
- Үндсэн арга (цэгийн утас руу код) ижил.
- Суурин утсанд **дуут код** ашигладаг нь манай нээлттэй асуудал Б3-ыг шийднэ.
- «Аль хэдийн эзэнтэй бол **Төлөөлөгч** болох» загвар манай AC 13–15 («Эзэмшигчээс хүсэлт гаргах», 7 хоног)-аас энгийн.
- Yandex цэг өмчлөхийг ID-ийн байгууллагаас **тусдаа** систем болгосон.

## 4. Найзуудтайгаа байршил хуваалцах

### 4.1 2ГИС: «Друзья на карте»

| Шинж | 2ГИС |
|---|---|
| Хаана | **Газрын зургийн апп дотор** «Друзья» таб (2023 оноос) |
| Найз нэмэх | QR код, мессенжерээр холбоос илгээх, утасны контакт ба VK-аас |
| Зөвшөөрөл | **Харилцан** найз болсон үед л бие биенээ харна. Утасны байршлын зөвшөөрөл шаардлагатай |
| Анхдагч | Бусад найзаас байршил **нуугдсан** байна |
| Унтраах | Давхаргын цэснээс өөрийн байршлыг харуулахаа зогсооно |
| Нэмэлт | Найзын чиглэл, emoji, ганцаарчилсан ба групп чат, найз руу маршрут гаргах |
| Нэг удаагийн хуваалцалт | «Поделиться геопозицией» → холбоос: **маршрут дуустал, 1 цаг, 8 цаг, 24 цаг**. Хүлээн авагч апп суулгах шаардлагагүй, хөтөч дээр нээнэ |
| **Хүүхдийн профайл** | 14-өөс доош насны хүүхэд. Хүүхдийг найзаар нэмэх → «хүүхдийн бүртгэл болгох» → хүүхдийн төхөөрөмж дээр **нэг удаагийн код**. Эцэг/эх байршил, **батерейны түвшин**, сургууль, гэрт ирсэн/гарсан мэдэгдэл (geofence), шинэ найз нэмсэн, утас унтарсан, байршил хаагдсан тухай мэдэгдэл авна. **Хүүхэд эцэг/эхээс байршлаа нууж, холбоосоо салгаж чадахгүй** |

### 4.2 Yandex Карты: «Поделиться, где я» (2026 оны 1-р сараас)

- Өөрийн цэгээ дарж хуваалцана. Хугацаа: **15 минут, 1 цаг, 8 цаг, 24 цаг, эсвэл зогсоох хүртэл**.
- Холбоосыг илгээнэ. Хүлээн авагч холбоосыг нээхэд **илгээгчид хүсэлт ирж, илгээгч зөвшөөрнө**. Хариуд нь «Поделиться в ответ» гэж хуваалцаж болно.
- Идэвхтэй хуваалцалтыг сунгах боломжгүй, шинээр үүсгэнэ. Апп хаалттай үед ажиллахын тулд байршлын байнгын зөвшөөрөл шаардлагатай.
- Yandex ID-ийн «Семья»-тай **холбоогүй**.

### 4.3 Kakao Map: «친구위치» (найзын байршил)

- KakaoTalk-ийн **чатын өрөөнөөс** эхэлнэ. Групп нь мессенжерийн групп чат, identity систем биш.
- Хүн бүр 10 хүртэл байршлын группт оролцоно. Группээр нь «байршлаа нуух», 1 цагийн дараа нуух тохиргоо бий.
- **Анхааруулга:** 2025 оны 11-р сард хугацааны хязгаарыг (15 мин – 6 цаг) **хасч**, хүн өөрөө зогсоох хүртэл хуваалцдаг болгосон. Үүний дараа «хяналт, тандалт» гэсэн шүүмж, апп-ын үнэлгээ унах зэрэг сөрөг хариу гарсан.

### 4.4 Бусад (өмнөх судалгаанаас)

- Apple: гэр бүл нь Apple Account-д (Family Sharing), байршил нь Find My апп-д.
- Google: гэр бүл нь Google Account-д, байршил нь Maps-ын «Location sharing»-д.
- Life360: «Circle» групп бүхэлдээ апп дотор.

## 6. Hamuga-д гарах дүгнэлт ба санал

### 6.1 Үүргийн хуваарь (өмнөх зөвлөмж батлагдав)

| Систем | Юу | Story |
|---|---|---|
| **Hamuga ID** | Байгууллага бүртгэх, баталгаажуулах (ДАН + ХУР), байгууллагын гишүүнчлэл, role, байгууллагын контакт; эцэг/эх–хүүхдийн холбоо; (сонголттой) захиалга, төлбөрийн «Гэр бүл» | NAV-025, NAV-027, NAV-028, NAV-029, NAV-024/026-ийн байгууллагын хэсэг |
| **Газрын зургийн апп** (Hamuga Map эсвэл Nav) | Найз, гэр бүл, бусад групп; байршил хуваалцах; хүүхдийн байршил | NAV-024/026-ийн найз, бусад хэсэг, NAV-030 A |
| **Hamuga POI engine / бизнес кабинет** | Бизнесийн цэг өмчлөх, засах | NAV-032, NAV-030 B |
| **Төлбөрийн систем** | Байгууллагын нэрээр төлөх | NAV-030 C, NAV-031 |

### 6.2 Байршил хуваалцах функцад авах загвар (апп-ын backlog-д)

1. **Анхдагчаар унтраалттай, хугацаатай:** 15 мин / 1 цаг / 8 цаг / 24 цаг / «зогсоох хүртэл» (Yandex, 2ГИС). Kakao-ийн хязгааргүй анхдагчийг **давтахгүй**.
2. **Харилцан зөвшөөрөл:** холбоос нээгдэхэд илгээгч зөвшөөрнө (Yandex). Найз хоёр талаасаа нэмэгдсэн байна (2ГИС). «Хариуд нь хуваалцах» товч.
3. **Группээр нуух:** тодорхой группээс түр нуух (Kakao).
4. **Апп-гүй хүлээн авагч:** холбоос хөтөч дээр нээгдэнэ (2ГИС).
5. **Хүүхдийн горим:** хүүхэд унтрааж чадахгүй, батерей, geofence, утас унтарсан тухай мэдэгдэл (2ГИС). **Hamuga-ийн давуу тал:** эцэг/эх–хүүхдийн холбоог нэг удаагийн кодоор биш, **ID-ийн ДАН холбоосоос** авна. Апп нь ID-аас «энэ хүн таны хүүхэд мөн» гэдгийг асууна.

### 6.3 Hamuga ID-д нэмж авах санаа

1. **Байгууллагын горим (account switcher):**
   - Хэрэглэгч профайлаас байгууллагаа сонгож, байгууллагын нэрээр апп-уудад нэвтэрнэ (Yandex).
   - Token-д `org_id`, `org_role` очно.
   - Шинэ story: «ID → апп-уудад байгууллага, role, гэр бүлийн холбоог өгөх API ба token claim».
2. **Урилгын холбоос:** утас, имэйлээс гадна хуулж илгээх холбоос (Yandex). NAV-026-д нэмэх санал.
3. **Байгууллагын устгах, эзэмшил шилжүүлэх:** Yandex-ийнхтэй ижил, манай загвар хэвээр. Харин Yandex-ийн гэр бүлд админ эзэмшлээ шилжүүлж чаддаггүй нь сул тал тул **давтахгүй**.

### 6.4 NAV-032-д авах санаа

1. Суурин утсанд **дуут код** (Yandex «Подтвердить звонком») → Б3-ыг хаах санал.
2. Цэг аль хэдийн эзэнтэй бол хүсэгчийг **«Төлөөлөгч»** болгох хувилбарыг AC 13–15-тай харьцуулж PO-д санал болгох.

### 6.5 PO-ийн шийдвэр шаардлагатай

| # | Асуулт | BA-ийн санал |
|---|---|---|
| 1 | Найз, бусад групп ба байршил хуваалцахыг ID-аас газрын зургийн апп руу шилжүүлэх үү? | **Тийм** (§5: аль ч платформ ID-д байрлуулаагүй) |
| 2 | Тэр функцыг аль апп эзэмших вэ: Hamuga Map эсвэл Nav? | PO / ICT Group |
