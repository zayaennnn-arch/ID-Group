# Backlog — Групп, байгууллагын бүртгэл (Hamuga ID)

Эх сурвалж: Nav Agile төслийн `docs/requirements/backlog-mn.md`-ийн эпикийн хэсэг. Эрэмбэ нь MoSCoW (`must` / `should` / `could` / `wont`), хэмжээ нь S / M / L. Төлөв: `draft` → `ready` → `in-progress` → `done`.


Эх сурвалж: «Групп, байгууллагын бүртгэл» эпик (Эпик (шинэ), Hamuga ID, **Critical**). Шаардлага 1–6 ба хурлын тэмдэглэлийг доорх story-нууд болгон задалсан.
- Бүх story **Hamuga-тай холбоотой ажлын босго (D38)**-д хамаарна. ICT Group-ийн бичгэн гэрээ байхаас өмнө `ready` руу шилжихгүй.
- Эрэмбийг PO батлаагүй байна (BA-ийн санал).

**Систем тус бүрээр ангилсан (2026-10-27, [ADR-0020](../architecture/adr/0020-hamuga-id-vs-apps-group-responsibilities-mn.md), PO «Тийм, шилжүүл»).** Зарчим: ID нь «хэн бэ, хэнийг төлөөлдөг вэ»-г, апп нь «юу хийх вэ»-г хариуцна.

| Систем | Тэмдэг | Story |
|---|---|---|
| Hamuga ID | `id` | NAV-024, NAV-025, NAV-026, NAV-027, NAV-028, NAV-029, NAV-035 |
| iMap («Групп» цэс, ADR-0020 A1) | `app` | NAV-033, NAV-034 |
| Hamuga POI engine / бизнес кабинет | `poi` | NAV-032, NAV-030 B |
| Төлбөрийн систем | `pay` | NAV-031, NAV-030 C |

**Санал болгож буй хүргэх дараалал:**
- **ID:** NAV-024 → NAV-025 ∥ NAV-027 → NAV-029 → NAV-026 → NAV-028 → **NAV-035** (апп-ын бүх story-ноос өмнө).
- **POI:** NAV-032 нь ID-аас зөвхөн ДАН Level 2 шаардана, тиймээс ID-ийн ажилтай зэрэгцэнэ. NAV-030 B нь NAV-035-ын дараа.
- **iMap:** NAV-035 → NAV-033 → NAV-034.
- **Төлбөр:** NAV-031 (spike, зэрэгцээгээр) → NAV-030 C (NAV-035-ын дараа).
