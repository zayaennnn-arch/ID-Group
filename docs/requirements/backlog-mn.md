# Backlog — Групп, байгууллагын бүртгэл (Hamuga ID)

Эх сурвалж: Nav Agile төслийн `docs/requirements/backlog-mn.md`-ийн эпикийн хэсэг. Эрэмбэ нь MoSCoW (`must` / `should` / `could` / `wont`), хэмжээ нь S / M / L. Төлөв: `draft` → `ready` → `in-progress` → `done`.


Эх сурвалж: «Групп, байгууллагын бүртгэл» эпик (Эпик (шинэ), Hamuga ID, **Critical**). Шаардлага 1–6 ба хурлын тэмдэглэлийг доорх story-нууд болгон задалсан. Бүх story **Hamuga-тай холбоотой ажлын босго (D38)**-д хамаарах тул ICT Group-ийн бичгэн гэрээ байхаас өмнө `ready` руу шилжихгүй. Эрэмбийг PO батлаагүй байна (BA-ийн санал).

**Санал болгож буй хүргэх дараалал:** NAV-031 (spike, зэрэгцээгээр) → NAV-024 → NAV-025 ∥ NAV-027 ∥ NAV-032 → NAV-026 → NAV-028 → NAV-029 → NAV-030.
