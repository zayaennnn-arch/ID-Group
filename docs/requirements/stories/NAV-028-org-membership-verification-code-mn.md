# NAV-028: Байгууллагын баталгаажуулах код

## Story
**Байгууллагын группт нэгдэх гэж буй ажилтан** миний хувьд **группын админаас авсан кодоор байгууллагад харьяалагддагаа баталгаажуулахыг** хүсч байна, ингэснээр **гадны хүн байгууллагын группт нэвтэрч орохгүй** болно.

## Нөхцөл байдал
Эх сурвалж: эпикийн шаардлага 3 («Байгууллагаа баталгаажуулахын тулд группын админ руу нь баталгаажуулах кодыг илгээх»). Зөвхөн «Байгууллага» төрлийн группт хамаарна (NAV-024). Байгууллагын өөрийнх нь хууль ёсны баталгаажуулалт бол NAV-029 (ДАН).

### Хэрэглэгчид харагдах string-үүд
- «Баталгаажуулах код», «Кодыг админ руу илгээлээ», «Код оруулах», «Код буруу байна», «Кодын хугацаа дууссан», «Дахин илгээх»

## Хүлээн авах шалгуур (AC)
1. **Өгөгдсөн нь** «Байгууллага» группт урилга зөвшөөрсөн эсвэл нэгдэх хүсэлт гаргасан хэрэглэгч, **Хэзээ** нэгдэх үед, **Тэгвэл** систем 6 оронтой нэг удаагийн код үүсгэж, группын **админ** (эзэмшигч ба админууд) руу апп дотор + push-оор илгээнэ.
2. Админ кодыг ажилтанд өөрийн сувгаар (биечлэн, ажлын чат) дамжуулна. Код ажилтан руу шууд **очихгүй**.
3. **Өгөгдсөн нь** «Код оруулах» дэлгэц, **Хэзээ** ажилтан зөв кодыг хүчинтэй хугацаанд (анхдагч 24 цаг) оруулахад, **Тэгвэл** «Баталгаажсан гишүүн» болж группт бүрэн нэвтэрнэ.
4. **Хэзээ** буруу код 5 удаа оруулахад, **Тэгвэл** 15 минут түгжигдэнэ. Хугацаа дууссан код хүчингүй.
5. Ажилтан «Дахин илгээх»-ээр шинэ код хүсэж болно (цагт хамгийн ихдээ 3 удаа). Шинэ код үүсэхэд хуучин нь хүчингүй болно.
6. Админ «Хүлээгдэж буй баталгаажуулалт» жагсаалтаас кодгүйгээр шууд «Зөвшөөрөх» эсвэл «Татгалзах» боломжтой.
7. Баталгаажаагүй гишүүн байгууллагын POI contribute, төлбөрийн үйлдэл хийх боломжгүй (NAV-030).

## Хязгаарын тохиолдлууд
- Админ байхгүй (зөвхөн эзэмшигч): код эзэмшигч рүү очно.
- Админ хасагдсан үед илгээгдсэн код: хүчинтэй хэвээр (кодыг групп рүү холбоно, админ руу биш).
- Сүлжээгүй: код оруулах боломжгүй, «Интернэт холболт алга».
- Brute-force: AC 4-ийн түгжээ + backend rate limit.

## Хамрах хүрээнээс гадуур
- Байгууллагын имэйлийн домэйноор автоматаар баталгаажуулах.
- Байгууллагын хууль ёсны баталгаажуулалт (NAV-029).
