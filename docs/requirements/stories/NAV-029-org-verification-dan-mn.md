# NAV-029: ДАН-аар байгууллага баталгаажуулах

## Story
**Байгууллагын эзэмшигч** миний хувьд **байгууллагынхаа бүртгэлийг ДАН системээр баталгаажуулахыг** хүсч байна, ингэснээр **манай групп «Баталгаажсан байгууллага» тэмдэгтэй болж, байгууллагын нэрийн өмнөөс төлбөр төлөх, POI оруулах** боломжтой болно.

## Нөхцөл байдал
Эх сурвалж: эпикийн шаардлага 6. NAV-028 нь *гишүүн* байгууллагад харьяалагдахыг баталгаажуулдаг бол энэ story *байгууллага өөрөө* хууль ёсны болохыг баталгаажуулна.

### Хэрэглэгчид харагдах string-үүд
- «ДАН-аар баталгаажуулах», «Баталгаажсан байгууллага», «Байгууллагын регистр», «Баталгаажуулалт амжилтгүй»

## Хүлээн авах шалгуур (AC)
1. **Өгөгдсөн нь** «Байгууллага» группын эзэмшигч, **Хэзээ** «ДАН-аар баталгаажуулах»-ыг дарахад, **Тэгвэл** ДАН-ын нэвтрэх/зөвшөөрлийн урсгал нээгдэнэ.
2. **Хэзээ** эзэмшигч ДАН-д нэвтэрч, байгууллагын мэдээлэл хуваалцахыг зөвшөөрөхөд, **Тэгвэл** байгууллагын регистрийн дугаар, албан ёсны нэр татагдаж, группт хадгалагдана.
3. **Өгөгдсөн нь** ДАН-аас ирсэн мэдээлэл, **Хэзээ** эзэмшигч тэр байгууллагын эрх бүхий этгээд (захирал / итгэмжлэгдсэн) болох нь баталгаажихад, **Тэгвэл** групп «Баталгаажсан байгууллага» тэмдэгтэй болно.
4. **Хэзээ** баталгаажуулалт амжилтгүй болоход (зөвшөөрөл өгөөгүй, эрх бүхий этгээд биш, регистр олдсонгүй), **Тэгвэл** шалтгааныг монгол хэлээр харуулж, групп «Баталгаажаагүй» хэвээр үлдэнэ.
5. Нэг байгууллагын регистрийн дугаар зөвхөн **нэг** баталгаажсан группт холбогдоно. Давхардвал «Энэ байгууллага аль хэдийн бүртгэгдсэн байна».
6. ДАН-аас авсан мэдээлэл зөвхөн шаардлагатай талбараар (регистр, нэр) хадгалагдана. Иргэний хувийн мэдээллийг хадгалахгүй.

## Хязгаарын тохиолдлууд
- ДАН систем ажиллахгүй / timeout: «Түр хугацааны дараа дахин оролдоно уу».
- Байгууллагын нэр өөрчлөгдсөн: дахин баталгаажуулах боломж.
- Эзэмшил шилжүүлэх (NAV-026 AC 9): шинэ эзэмшигч дахин баталгаажуулах шаардлагатай эсэх (Нээлттэй асуулт 2).
