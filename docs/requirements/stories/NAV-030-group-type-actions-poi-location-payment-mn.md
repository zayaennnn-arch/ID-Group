# NAV-030: Группын төрлөөр үйлдлүүд

## Story
**Группын гишүүн** миний хувьд **группынхаа төрлөөс хамааран байршлаа хуваалцах, газрын зурагт газар (POI) нэмэх, төлбөр төлөх үйлдлүүдийг хийхийг** хүсч байна, ингэснээр **гэр бүл маань хаана байгааг мэдэх, байгууллага маань газрын зураг дээр зөв мэдээлэлтэй байх** боломжтой болно.

## Нөхцөл байдал
Эх сурвалж: эпикийн шаардлага 5 («Группын төрлөөс хамааран POI contribute хийх, байршил хуваалцах, төлбөр төлөх гэх мэт үйлдлүүдийг хийх боломжтой байх»). Хэн юу хийж болохыг NAV-027-ийн матриц тодорхойлно.

## Хүлээн авах шалгуур (AC)
### A. Байршил хуваалцах — **шилжсэн**
1–3. ~~Байршил хуваалцах~~ → [NAV-033](NAV-033-app-groups-location-sharing-mn.md) B хэсэг (газрын зургийн апп, [ADR-0020](../../architecture/adr/0020-hamuga-id-vs-apps-group-responsibilities-mn.md)). AC-ийн дугаарыг мөшгилтөд зориулж хэвээр үлдээсэн.

### B. POI contribute
4. **Өгөгдсөн нь** «Байгууллага» групп ба POI эрхтэй хэрэглэгч, **Хэзээ** байгууллагынхаа газрыг (салбар, оффис) нэмэх/засахад, **Тэгвэл** POI «Байгууллагын баталгаажсан» гэсэн тэмдэгтэй хадгалагдана.
5. Баталгаажаагүй байгууллага (NAV-029) POI санал болгож болох ч хянагдсаны дараа нийтлэгдэнэ.

### C. Төлбөр төлөх
6. **Өгөгдсөн нь** баталгаажсан «Байгууллага» групп (NAV-029), **Тэгвэл** эрх бүхий role-тэй хэрэглэгч байгууллагын нэрийн өмнөөс төлбөр төлж болно. Дэлгэрэнгүй дүрмийг NAV-031-ийн дараа нарийвчилна.

### D. Ерөнхий
7. Группын төрөлд хамааралгүй үйлдэл UI дээр **харагдахгүй** (идэвхгүй биш, нуугдана).
8. Төрөл бүрт аль үйлдэл нээлттэй байхыг feature flag-аар удирдана.

## Хязгаарын тохиолдлууд
- Байршлын зөвшөөрөл олгоогүй: хуваалцахыг асаахад NAV-005 AC 8–12-ын адил зөвшөөрлийн урсгал.
- Арын горимд байршил хуваалцах: батарей, Android-ын арын хязгаарлалт (NAV-012-той уялдуулна).
- Сүлжээгүй: сүүлийн мэдэгдэж буй байршлыг цагтай нь харуулна.
